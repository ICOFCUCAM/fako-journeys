# The system audit — instruction 1

**Measured, not asserted.** Every figure below comes from the repository as it
stands at `1ca0139`. Nothing was changed to produce it.

The finding, before the detail:

> **The site is not a design system with variations. It is twenty-four design
> systems sharing a colour palette.**
>
> Ten mastheads, seven footers, twenty-four class prefixes, seventeen
> stylesheets and 183 distinct type sizes serve 1,597 pages that are built from
> six page families. The engineering underneath is disciplined; the surface is
> not, and the two have never been compared.

**Every page is generated.** `cameroon.html` is hand-built and even it is
rewritten by four late passes. There is no page a designer can edit directly,
and that is the single most important fact for the migration plan: *a visual
change lands in a generator or a stylesheet, never in HTML.*

## 2 — The global shell does not exist

There are **ten mastheads** and **seven footers**.

| masthead | pages | what it is |
|---|---|---|
| `pl-mast` | 1,461 | places + portraits |
| `fj-mast` | 60 | tourism (55) **and the operator's own pages (5)** |
| `mast` | 52 | country home pages |
| `jn-mast` | 17 | journey builder, trans-afrique |
| `jf-mast` | 3 | journey fund |
| `wa-` `mt-` `at-` `top` | 1 each | homepage, meet, atlas, one more |

### The identity collision worth naming

`fj-mast` is worn by two different products. On `/tourism/kenya` it carries
Afrinkong's navigation. On `/about`, `/contact`, `/pricing`, `/services` and
`/cameroon` it carries the **Kamerun operator's** — *Circuits · Rates & Fees ·
The Operator · Enquire*, pointing at `/services`, `/pricing`, `/about`,
`/contact`.

Both are correct for their page. **They share a class name and share nothing
else**, which means any change to `.fj-mast` changes two products at once. This
is exactly the "one platform, multiple experiences" problem instruction 5 names
— and here it is already a hazard rather than a design.

### 1,529 of 1,597 pages carry no `body` class

| body class | pages |
|---|---|
| *(none)* | **1,529** |
| `po-body` | 54 |
| `tf-body` | 10 |
| `tr-body` · `jf-page` | 3 each |
| `sx-` `hw-` `wo-` | 1 each |

Nothing in the markup says what kind of page it is, so nothing can be styled
*by kind*. That is the mechanical reason every stylesheet re-specifies
everything.

### Type, space and elevation

| | measured | verdict |
|---|---|---|
| distinct `font-size` values | **183** | no scale; the token layer declares 11 |
| distinct breakpoints | **31** | three carry the majority: 900 (44), 560 (25), 760 (25) |
| distinct `border-radius` | **4** — `0`, `2px`, `.3rem`, `50%` | **already disciplined.** The site is sharp-cornered and should stay that way |
| distinct `box-shadow` | **22** | no elevation language; 22 opinions |

The radius finding matters more than it looks. Instruction 10 warns against
"oversized rounded cards everywhere" — **the site has never had them.** The
existing visual language is rules, not shadows and corners, and the premium
direction should sharpen that rather than import a softer idiom.

## 5 — The image system is the strongest thing here

| | |
|---|---|
| `<img>` tags | 7,016 |
| `<picture>` | 1,994 |
| **nested `<picture>`** (a known defect) | **0** — fixed |
| missing `alt` | **0** |
| decorative `alt=""` | 3,003 |
| `width`+`height` set | 6,972 |
| **missing `width`/`height` (CLS risk)** | **44** |
| `loading="lazy"` | 4,076 |
| **`loading` unset** | **2,940 (42%)** |
| `fetchpriority` | 1,426 |
| `srcset` | 1,850 (26%) |
| `sizes` | 3,326 (47%) |

Two real findings: **2,940 images have no `loading` attribute**, so the browser
treats them as eager; and only 26% carry a `srcset`. Both are addressable in
the existing late passes (`bound`, `srcset`, `sizeattr`, `modern`) rather than
by touching pages.

## 6 — Accessibility structure is already good

| | measured |
|---|---|
| pages with no `<h1>` | **0** |
| pages with multiple `<h1>` | 2 (`index.html` ×5, `journey.html` ×7) |
| skip link | 1,596 / 1,597 |
| `<main>` landmark | 1,596 |
| `lang` attribute | 1,597, all `en` |
| heading-level jumps | 8, all `h1 → h3` |
| dangling `aria-labelledby` | 0 (51 were introduced and fixed this session) |

This is a better baseline than most commercial sites. The gaps are **two
multiple-`h1` pages, eight heading jumps, and one page missing `<main>`** — a
morning's work, not a project.

What is *not* covered: focus-visible treatment, touch-target sizes below 24px,
and colour-contrast on the tone chips are unmeasured and belong to Phase 9.

## 7 — States

`docs/state-language.md` now names **72 states, 6 tones**, and one surface has
adopted it. The other 71 sentences exist and are unused, correctly: issuance is
off, the wallet is unwired, there are no bookings.

**The gap is no longer vocabulary. It is surfaces.**

---

## 8 — What the audit did NOT find

Recorded because a design audit that only produces complaints is not an audit:

- **No nested `<picture>` blocks.** Previously 36; now zero.
- **No missing alt text**, across 7,016 images.
- **No rounded-card sprawl.** Four radius values, three of them structural.
- **No dead internal links.** 80,367 links, all resolving, all fragments valid.
- **No `!important` epidemic** in the shared sheet.
- `tourism/compare.html` is a `noindex` internal review sheet with no
  stylesheet — **tooling, not an unstyled product page.** Flagged and cleared.

The engineering discipline instruction 16 asks to preserve is real and is
visible in the measurements. The surface has simply never been held to the same
standard.

## 9 — The five structural problems, ranked

| | problem | measured | cost to fix |
|---|---|---|---|
| 1 | **no global shell** | 10 mastheads, 7 footers | high — but only 6 generators |
| 2 | **no page identity** | 1,529 pages with no `body` class | low — one line per generator |
| 3 | **no type scale** | 183 sizes; token layer applied to nothing | medium — 15 source stylesheets |
| 4 | **no elevation language** | 22 shadows, 31 breakpoints | low |
| 5 | **no shared components** | 24 prefixes, 14 cards, 6 buttons | high — the real work |

Problem 2 is the cheapest and unblocks 3 and 5: **nothing can be styled by kind
until the markup says what kind it is.**
